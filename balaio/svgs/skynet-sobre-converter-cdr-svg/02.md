## ✅ O MELHOR FLUXO (recomendado para bordado)

### 🥇 **CDR → SVG → Photopea**

Esse é o caminho mais seguro **online e gratuito**.

1. **Converta o CDR para SVG**
   👉 [https://cloudconvert.com/cdr-converter](https://cloudconvert.com/cdr-converter)

   * Escolha **SVG**
   * Não redimensione
   * Baixe o arquivo

2. **Abra o SVG no Photopea**
   👉 [https://www.photopea.com/](https://www.photopea.com/)

   * `File → Open`
   * Abre camadas, curvas, textos (se ainda forem textos)
   * Dá pra:

     * Ajustar letras
     * Corrigir espaçamentos
     * Alterar cores
     * Exportar PNG/PDF pra bordado

📌 **Vantagem:**
Funciona muito bem quando você já tem **texto convertido em curvas**, que é o padrão correto pra bordado.

---

## 🧵 ESPECÍFICO PARA BORDADO (detalhes importantes)

Como você já tem:

* ✔️ versão **original**
* ✔️ versão **em curvas**

👉 **USE SEMPRE A VERSÃO EM CURVAS**
Isso evita:

* Fonte quebrar
* Letra mudar
* Problemas na matriz do bordado

No Photopea:

* Cada letra vira um shape
* Dá pra ajustar espessura visual
* Conferir se nenhuma letra “fechou” demais (bordado odeia detalhes muito finos)

## 🧠 DICA DE OURO (experiência real de bordado)

Antes de enviar pra quem vai bordar:

* Exporte em **PDF vetorial** e **PNG grande (300dpi)**
* Confira:

  * Espessura mínima das letras
  * Se não há linhas muito próximas
  * Se o escudo não tem detalhes invisíveis em tecido

Photopea faz isso tranquilamente.
